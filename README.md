# FreeCAD Carry – Projektmappe

**Live:** <https://danielgloeckler.github.io/freecad-carry/>

Digitale Projektmappe zum **Carry**-Projekt aus „FreeCAD Anleitung II“:
Chassi, Rad, Radlager, Achse/Schrauben und die Baugruppe – alle **24 Seiten**
(Seiten 2–25) als zoombare Originalseiten.

## Bedienung

- Kapitel links anklicken oder die Seitenzahlen darunter
- **← / →** blättern, **+ / −** zoomen
- **Seite anklicken** → Vollbild
- Direktlink: `index.html#seite-12`

## Inhalt

| Kapitel | Seiten | Thema |
|---|---|---|
| Projekt Carry | 2 | Ziel, Bauteile, Überblick |
| Kapitel 1 · Chassi | 3–6 | Skizze, Aufpolstern, Lochmuster, Senkungen |
| Kapitel 2 · Rad | 7–10 | Rotationskörper, polares Muster |
| Kapitel 3 · Radlager | 11–16 | geschlossener Linienzug, Hilfsebenen |
| Kapitel 4 · Achse & Schrauben | 17–19 | geometrische Körper, Fasteners |
| Kapitel 5 · Baugruppe | 20–25 | Carry zusammensetzen |

Das Uhren-Projekt (ab Seite 26) ist **nicht** enthalten.

## Quelle und Rechte

Die Seiten stammen aus **„FreeCAD Anleitung II – Fortgeschrittene
Konstruktionen und Baugruppen“** von **Jürgen Gräber** (2020), bereitgestellt
für den NWT-Unterricht. Text und Bilder bleiben Eigentum des Autors; diese
Mappe ist eine digitale Leseausgabe für den Unterricht.

## Technik

- statische Seite, keine externen Bibliotheken
- Seitenbilder: `pages/page-02.jpg` … `page-25.jpg` (1200 px breit)
- aus der PDF gerendert (140 dpi) und als JPEG gespeichert
